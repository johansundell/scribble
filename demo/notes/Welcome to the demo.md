# Welcome to the demo

This is a public demo of [scribble](https://github.com/johansundell/scribble), a small notes server with a web app, a command line client (`sn`) and a desktop app.

**Everything here is reset every night.** Your notes, deleted notes and history all go, and these sample notes come back. Anyone with the PIN can read and change what you write, so don't put anything private here.

Things to try:

- Open [[Markdown tour]] to see what a note can hold.
- Click the #scribble project to list the notes in it.
- Open [[Work log]] and look at its history: the reset edits it, so it has old versions to compare and restore.
- Make a note of your own, and link to it from here with `[[` and its title.
- Share a note: anyone with the link can read it, without the PIN.

This note is pinned, so it stays at the top of the list. See [[Using sn with the demo]] to try the command line client too.
